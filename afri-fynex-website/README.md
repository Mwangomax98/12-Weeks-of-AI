# Afri Fynex Solutions Limited website

A one-page website with no build step. Open `index.html` in a browser to view it.

## Files
- `index.html`: all the text and sections
- `styles.css`: colours, layout and animations
- `script.js`: menu, animations and the forms
- `images/`: logo, favicon and founder photos

## Common edits
- **Colours**: change the values under `:root` at the top of `styles.css` (`--navy` and `--orange` come from the logo).
- **WhatsApp number for the forms**: change `WHATSAPP_NUMBER` on the first line of `script.js`.
- **Phone, address and WhatsApp links**: search `index.html` for `255753418105` and `Magila Street`.
- **Founder photos**: replace the files in `images/` and keep the same file names.
